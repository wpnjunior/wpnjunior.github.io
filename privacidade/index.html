Política de Privacidade

Esta política explica como o Agendador Novaes trata dados, em conformidade com a Lei Geral de Proteção de Dados (Lei 13.709/2018).

Quem é o responsável

Dr. Wagner Novaes Jr., administrador único da ferramenta. Contato: fertilidadeadois@gmail.com.

Quais dados usamos

  • Identificador e nome de usuário das contas do Instagram, TikTok e YouTube que o próprio administrador conecta.
  • Tokens de acesso fornecidos por essas plataformas, usados apenas para publicar o conteúdo que o administrador aprovou.
  • Os textos, vídeos e imagens que o administrador agenda.

Não coletamos dados de seguidores, visitantes ou terceiros, e não usamos dados para publicidade.

Para que usamos

Exclusivamente para agendar e publicar conteúdo nas contas do administrador, no horário e na forma que ele aprovou.

Onde ficam e por quanto tempo

Os dados ficam em banco de dados protegido (Supabase), com acesso restrito ao servidor da ferramenta. Arquivos de mídia são apagados depois de publicados. Tokens são apagados quando a conta é desconectada.

Compartilhamento

Os dados são enviados apenas à plataforma onde o conteúdo será publicado (Meta, TikTok ou Google). Não vendemos nem cedemos dados a terceiros.

Exclusão de dados

Para apagar todos os dados de uma conta, desconecte o aplicativo nas configurações da plataforma (Instagram: Configurações > Apps e sites; TikTok: Configurações > Segurança > Apps; Google: myaccount.google.com/permissions) ou envie um e-mail para fertilidadeadois@gmail.com. A exclusão é feita em até 30 dias.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. A ferramenta usa a API do YouTube apenas para enviar vídeos ao canal do administrador. Veja também os Termos de Serviço do YouTube e a Política de Privacidade do Google.

Seus direitos

Você pode pedir acesso, correção ou exclusão dos seus dados pelo e-mail acima.
